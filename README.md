# Student Performance Analysis Dashboard

## Project Overview
This project analyzes student performance data using Excel, SQL, Python, and Power BI. The dashboard helps identify performance trends based on gender, parental education, lunch type, and test preparation course completion.

## Tools Used
- Excel
- SQL
- Python
- Power BI

## Features
- Interactive dashboard
- KPI cards
- Slicers and filters
- Gender-wise analysis
- Test preparation analysis
- Parental education analysis
- Top 5 student analysis

## Files Included
- Dataset CSV
- Power BI Dashboard
- Project Report
- Dashboard Screenshot

## Key Insights
- Students who completed test preparation scored higher
- Reading and writing scores showed strong correlation
- Standard lunch students performed better on average
